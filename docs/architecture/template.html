RejectLess — Production Technical Architecture

Privacy-first application-readiness platform: documents are read and validated on the citizen's device; servers only deliver code, signed knowledge and AI explanations.

Version 1.0 · November 2026
Scope: EPFO, NSP, PM-KISAN, ITR-1 and the scheme catalogue
Local-firstDocuments never leave the device; originals are not retained.
Code decides, AI explainsEvery result comes from deterministic, tested rules.
Source-backed rulesVersioned, signed rule packs with citations and effective dates.
Humans approve knowledgeAI drafts rule changes from circulars; reviewers publish.
Zero PII on serversOnly redacted summaries cross the network, with consent.

2 Edge & delivery

Global delivery of code and signed knowledge. Every request is TLS-terminated and filtered here.

Versioned asset store

Cloudflare R2
  • Signed rule packs + manifest (semver, effective dates)
  • OCR models (eng, hin) and WASM cores
  • Portal form schemas for autofill
  • Dated IFSC reference set

Vercel Edge Network

Vercel CDNFirewall / WAFTLS 1.3
  • Static app shell and code-split bundles, immutable caching
  • WAF, bot protection, DDoS mitigation, per-IP rate limits
  • Content-Security-Policy, Subresource Integrity, HSTS
  • Routes API traffic to application services

5 Knowledge operations — keeping rules current (AI drafts, humans approve, every rule versioned and cited)

A back-office pipeline turns new circulars and notifications into reviewed, tested, signed rule packs.

Official sources

Source registry
  • e-Gazette notifications · EPFO circulars · NSP guidelines · PIB · Income Tax · RBI IFSC master
  • Each source linked to the rules that depend on it

Scheduler & change detection

GitHub Actions cron
  • Daily fetch of every registered source
  • Content hashing detects new or changed documents

Extraction & AI drafting

OCR (Hindi + English)Groq
  • Text extracted from PDFs and scanned circulars
  • LLM proposes rule changes in the rule schema, with exact quotes and page references

Sign & publish

Ed25519 signingR2
  • Versioned rule pack + manifest with effective-from / until
  • Devices verify signatures before use

CI quality gate

VitestPlaywright
  • Unit and rule-boundary tests
  • Seeded scenario regression + end-to-end flows

Human review

Pull request
  • Domain reviewer checks quotes against the source
  • Only approved changes are labelled "Official"

Registry database

PostgreSQLNeon
  • Sources, rule versions, approvals, audit log

Public circular archive

R2
  • Snapshots of public source documents only — never citizen data

Staleness monitor

Grafana alerts
  • Flags rules not re-verified in 90 days; devices show "check the portal"
